# Localization maintenance

FALSEWAKE v0.4 supports English (`en`), Simplified Chinese (`zh-Hans`), Spanish (`es`), and Japanese (`ja`) in both modes. A labelled header selector redraws the interface without restarting the investigation. Proper seat numbers, canonical role IDs, symbols, and all engine/replay values stay language-independent. User notes remain exactly as entered.

## Catalogs

`web/i18n.js` combines `web/locales/ui.js`, `game.js`, `help.js`, and `rules.js`. The last file adds the v0.4 capabilities, short numbered predicates, updated rules, and save-version notices. Rows contain English source ID, Chinese, Spanish, and Japanese. The English source string is a stable key; row order is irrelevant. Unused historical source IDs can remain for documentation/tests, but must not be rendered as current rules.

`t` returns text, `tr` allows only catalog-owned attribute-free `strong`, `em`, `kbd`, `code`, and `br` markup, and `ta` escapes attribute text. Parameter values are escaped separately. Preserve placeholders exactly and translate whole sentences rather than concatenating English grammar. `Intl` formats lists and numbers. Grimoire search accepts original and translated role text and normalizes accents.

The new observation templates must preserve logical distinctions: **any**, **none**, **both**, **not both**, **exactly one**, **same apparent team**, and **different apparent teams** are not interchangeable. Apparent/registered Evil must never be translated as confirmed true allegiance. Drunk is permanent; Taint is temporary. A Burden/impairment reading is not a team reading.

## Selection and persistence

Priority is supported `?lang=`, saved preference, first supported `navigator.languages` entry, then English. Regional English, Spanish, and Japanese tags use their base language. `zh`, `zh-CN`, `zh-SG`, and `zh-Hans` variants map to Simplified Chinese; Traditional Chinese is not silently relabelled. Invalid preferences fall through. Storage failure still permits an in-memory switch.

The preference key remains `falsewake.language.v1`. New rule saves use v2 keys, independently of language. Both v2 numeric C ABIs and replay formats produce identical results across languages. Old rules-v1 saves are not migrated just by changing the locale.

The no-JavaScript fallback is English. Browser-origin technical diagnostics may use the browser's language. These translations are an initial editorial pass, not an independent native-speaker review.

## Adding a language

Add a canonical tag/autonym to `LOCALE_CODES`/`LANGUAGE_NAMES`, deliberate normalization, and a full column in every catalog. Keep placeholders and allowed inline markup. Add the locale to the unified browser matrix and inspect 1440/390/320px captures. Right-to-left support needs direction-aware layout work before claiming support. Do not call a partial catalog complete.

Run `npm test` and `npm run test:browser`. Tests check completeness, uniqueness, placeholder/markup parity, fallback, escaping, every role/event/predicate, live switching, numeric replay/solver parity, and both full case victories in all languages. CI installs CJK fonts so the browser screenshots contain real glyphs, not missing-character boxes. Runtime fonts remain local/system fonts; no translation service or CDN is used.
